# Security

Do not report real Telegram or OpenAI credentials publicly. Contact contact@harshitethic.com to report a vulnerability with sanitized reproduction steps.

If you ever committed a key—even if you removed the file afterward—revoke/rotate the key. Git history retains older commits.

This code is a legacy reference. It does not implement rate limits, audit logging, moderation, or the protections needed for an untrusted public deployment.
